# Fit/Gap-анализ
## Проект «Цифровой аукцион алмазов» компании Diamond Universe

---

## 1. Список систем

| Система | Новая / существующая | Функциональность | Новая / существующая функциональность | Необходимые доработки |
|---|---|---|---|---|
| **ИС «Алмазы»** | Существующая | Отбор алмазов для цифрового аукциона, планирование работ | Новая | - Статус/признак «отобран для цифрового аукциона» <br> - Формирование планового задания на отправку в лабораторию |
| **ИС «Логистика»** | Существующая | Доставка алмазов в лабораторию и обратно | Новая | - Новый маршрут «офис → лаборатория → офис» <br> - Статус «на оцифровке» <br> - Уведомление о доставке/готовности к возврату |
| **ИС «Аукцион»** | Существующая | Проведение аукциона онлайн (публикация цифрового описания камней, дистанционное участие покупателей) | Новая | - Загрузка и отображение цифрового описания камней <br> - Личный кабинет для дистанционных покупателей <br> - Приём ставок онлайн |
| **ИС «Бухгалтерия»** | Существующая | Актирование и оплата услуг лаборатории | Новая | - Новый контрагент «лаборатория» в справочнике <br> - Новый вид акта за услуги оцифровки |
| **ИС «Лаборатория»** | Новая (у внешнего подрядчика) | Приём партии камней, лабораторный анализ (размер, чистота, флуоресценция, включения, форма), формирование цифрового описания, возврат камней | Новая | - Требования к составу/качеству цифрового описания <br> - Регламент приёма/возврата и подтверждения сохранности партии <br> - Защищённый канал передачи данных в «Аукцион» и «Бухгалтерию» <br> - Уведомление «Логистики»/«Алмазов» о готовности к возврату |

## 2. Список интеграций

| Интеграция | Новая / существующая | Реализация | Данные (новые / существующие) |
|---|---|---|---|
| **ИС «Алмазы» → ИС «Логистика»** (план перевозки) | Существующая / новая ветка (в лабораторию) | Автоматически | Существующие (реквизиты партии) + новые (адрес лаборатории, сроки, статус) |
| **ИС «Логистика» → ИС «Лаборатория»** (передача камней) | Новая | Автоматически | Новые: номер партии, перечень камней, дата отправки, перевозчик |
| **ИС «Лаборатория» → ИС «Логистика»** (готовность к возврату) | Новая | Автоматически | Новые: номер партии, статус готовности, дата возврата |
| **ИС «Лаборатория» → ИС «Аукцион»** (цифровое описание камней) | Новая | Автоматически | Новые: описание камня, номер, статус оцифровки |
| **ИС «Лаборатория» → ИС «Бухгалтерия»** (актирование услуг лаборатории) | Новая | Автоматически | Новые: перечень камней, объём и стоимость услуг |
| **ИС «Логистика» → ИС «Бухгалтерия»** (актирование перевозчика) | Существующая, частично новая | Автоматически (после доработки маршрутов) | Существующие (акты) + новые (маршрут в лабораторию) |
